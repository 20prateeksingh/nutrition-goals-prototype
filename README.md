# Nutrition goals — clickable prototype

A **desktop-web design exercise**: a Nutrition goals module for a restaurant-booking product,
letting a diner set dietary and nutrition goals, see how their meals out are landing, and get
restaurant and dish recommendations.

**▶ [Open the prototype](https://20prateeksingh.github.io/nutrition-goals-prototype/)**

Twelve screens, signed-in and signed-out. Bottom-centre controls let you switch surface, switch
between the signed-in and signed-out captures, drive each screen's states, highlight what is
clickable, and run a short walkthrough of what the design changed.

## ⚠ Not affiliated with OpenTable

This is an **unaffiliated student-style design exercise**, made for an interview. It is built on top
of saved copies of OpenTable pages so that new design work sits in the real product's context
instead of a blank canvas — the standard way this kind of exercise is done.

- It is **not** OpenTable, not endorsed by OpenTable, and not connected to any OpenTable service.

  the nutrition goals module — is the only original contribution.**

## Privacy

The captures were taken from a personal account. Before publishing, the account email, phone number
and the reservation's security token were **removed and replaced with placeholders**, and the
unreferenced reference captures were dropped entirely. The build script that does this, and the
check that refuses to ship an unclean bundle, live in the private working repo.

## How it was made

Generated from a documented design process — requirements, research, persona, user stories,
information architecture, wireframes, validation, UX copy, prototype. That record is not public.
